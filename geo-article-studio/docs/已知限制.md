# 已知限制

v1.1增加通用Agent协议和四种安装目标。generic能力声明不证明真实宿主支持；Claude Code及其他平台尚未实机联调。Hermes下述真实结果来自v1.0；v1.1的安装和执行回归单独报告。纯聊天Agent缺少文件/终端工具时无法运行本执行层。
与未验证项

这是轻量本地技能，不是完整平台。以下限制不能用离线通过掩盖。

1. Hermes实测只完成技能发现、自然语言加载、真实终端doctor/form、Qwen结构化预检桥接及等待批准。自然语言直接完成表单的两个尝试受shell/路径引号影响超时；没有验证自然语言百分之百命中、完整生产任务或显式斜杠命令的实际会话分发。参考[真实联调记录](Hermes真实联调记录.md)。
2. 本机实际默认模型为DeepSeek；生产请在Hermes明确选择已接入Qwen。本地Qwen小模型一次返回多余字段被拒绝，纠错重试成功；其预检文字仍有“产品图作为功能证据”的不恰当表述，保留待人工审查，没有批准。不能把JSON合法当语义正确。
3. 真正视觉推理未验证。配置visual_capability只是宿主能力声明，必须有实际验证引用，并真实查看生成图及基准图；Python不能从一个reviewer字段证明模型看过图片。没有视觉能力时自动图文任务阻断，学习模式可人工看图，明确标记human。
4. 第三方真实图片API未调用，无服务协议、凭据及费用授权。所实现的是同步OpenAI兼容风格generation JSON / edits multipart协议，包含真实参考bytes和URL/base64返回；不是任意厂商通用适配器。不支持异步job查询，query明确返回unsupported。UNKNOWN状态要人工核对账单/结果，再resolve-request或recover-image，禁止盲重发。
5. 金额预算依赖用户提供的真实每请求计价依据与币种；实际费用未由服务商对账。无价格仅使用请求次数上限并报告费用未知；不能保证提供方计费规则变化后仍满足金额硬上限。
6. Windows Python3.11.16已实际测试中文/空格路径、文件symlink、跨进程锁和复制中断恢复。Linux/WSL/容器/远程挂载未实际运行；映射只接受显式配置与交付访问验证引用，不能自动证明用户机器可访问。未做真实断电、网络文件系统锁、跨卷硬件故障测试。
7. DOCX/XLSX/可提取文本PDF已使用实际可选解析器读取虚构文档验证；复杂排版、表格语义/图表、密码保护和扫描PDF没有全部覆盖。OCR未实现，截图聊天不能当已提取文本。UTF-8/BOM及GB18030严格回退会记录；不能识别所有错误但恰好可解码的编码组合。
8. 中文检索为本地字符n-gram排序，无向量语义服务。每条索引最多4000字符并标truncated；模型上下文每片段最多800字符，按需retrieve补充。会话统计至多1000命中并标上限；不能声称完整分析全部客户。简单正则脱敏不保证所有姓名和健康详情被识别，仍需独立语义隐私审核。
9. 自动部分失败策略固定pause_all：保存已完成整篇，其余暂停。没有实现“跳过问题篇继续其余”的调度选项，不声称完成未交付篇目。没有自动发布、定时或排名监测。
10. actor/user_ref和图片授权是受信任宿主记录，不是强认证。具有本地文件写权限的人可改JSON或伪报身份；不防恶意操作系统管理员。规则语义冲突由当前模型/人工审核，程序只确定性拒绝同范围conflict_key冲突、词语/数值/来源/版本不符等可检查问题。
11. 从已完成任务修改会创建新任务重新预检与选择，保留旧成品；不在旧成品上原地覆盖。单张图修改可使用revise --image-id，只清理受影响图；正文实质变化会使本篇全部配图失效。
