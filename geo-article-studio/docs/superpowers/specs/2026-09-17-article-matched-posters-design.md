# 图文匹配海报设计

用户选定：T01 的两张新图都采用参考图库的图文海报方向。第一张讲“往返路程与预留余量”，第二张讲已批准资料中的三种电池续航；两张都出现当前 218轻便侠，并保留 3:4 独立成图。

现状：图片计划只绑定段落序号和用途；生成提示词可只写场景，无法证明画面包含该段落的判断内容。参考图虽有标题、信息块和醒目的视觉层级，上次的场景描述却排除了海报、贴纸和原有版式，因而两图都退化成户外产品照。旧图须保留，以新任务生成修订版。

设计：每张图片计划新增准确摘自正文的 `content_anchors`、将这些内容转为画面元素的 `visual_mapping`、`visual_kind` 和 `reference_style`。执行层用这些字段重建提示词，并在付费前检查锚点确实出现在正文、图数不少于两张时具有图文信息海报、不可把同一信息重复用于所有图片。借鉴参考图的海报视觉层级须有当前用户授权，只能借鉴风格，不得继承参考图旧产品、旧文案、人物身份或未经批准的卖点。可用文字仍须逐行直接摘自正文，产品参数必须关联批准事实；海报最多四行、每行不超过 16 个非空白字符。视觉审核新增逐图检查：正文锚点是否实际可见、数值是否正确、是否真正借鉴参考图的图文层级、两张图的信息是否互补。图片仍由配置的第三方 API 在同一次请求中读取批准产品图与批准参考图，生成完整画面；不合格图不得导出。

本次具体画面：封面用社区路线和家—目的地—家回程视觉、余量标识、218产品，借鉴参考图的大字标题和图形强调；第二张用三档电池续航的三个清晰信息块及218产品，借鉴参考图的信息卡片组织。所有公里数来自已批准的 fact_06459fdffc20d27ed106647c，不解释成实测或保证值。保持产品透视、地面接触和光影融合，若文字错字、数值错误或产品错款，视觉审核失败。
