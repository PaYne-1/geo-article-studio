# 人工图片复核与空间关系判断

用户已确认的设计：图片审核将人物实际动作与二维画面造成的透视、遮挡或空间错位分开记录。仅凭局部重叠不能断定人物踩踏、乘坐或操作产品；不确定时记录不确定性。

当前任务的用户明确接受图片时，执行层在现有图片和稿件哈希校验后，原子化记录人工视觉通过、用户引用、图片 ID 和内容版本，覆盖当前模型的失败结论并进入终审。此决定只适用于当前文章的当前图片版本，不激活长期宽松规则、不增加图片调用，也不改变未来任务标准。

自动任务如因图片修订临时进入学习确认，当前图片得到人工接受后恢复自动模式，终审继续由宿主模型独立完成。原本的学习任务保持学习模式。

验证包括失败审核到人工接受的状态转换、过期动作和不存在图片的拒绝、无新 API 请求、当前图片版本审计以及视觉审核提示词的分类要求。
