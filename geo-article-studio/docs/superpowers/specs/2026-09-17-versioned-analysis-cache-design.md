# 跨任务聊天分析复用

用户确认：在新任务的资料、产品事实、正式规则和运行配置完全一致时，复用上次通过结构与来源校验的聊天主题分析，省去重复文字模型调用。复用后仍停在人工选题；文章策划、正文、图片和各轮审核均不复用或跳过。

本地缓存只保存主题分析结果、来源任务和输入指纹。指纹覆盖产品及版本、已索引来源及哈希、已批准事实、正式规则快照、运行配置、聊天范围、任务额外要求、GEO 简报、文字来源和编辑标准版本。任何一项变化都视为未命中。缓存文件放在独立运行工作区，不能装入技能 ZIP。

`next-action` 在 ANALYZING 阶段发现有效缓存时返回 `NEEDS_TOOL/reuse-analysis`。执行工具重新校验当前来源文件、事实、规则、动作版本和缓存内容，原子写入当前任务的分析结果与复用审计，然后进入 `WAITING_SELECTION`。未命中时沿用原模型或文字 API 路径。缓存不代表 OpenViking 集成，也不充当客户资料的事实来源。
