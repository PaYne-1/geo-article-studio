# v1.3.0 更新与测试

日期：2026-09-14。用户要求在开始任务后选择默认模型或第三方文字API，并提前持久化服务配置。

## 交付行为

两个触发词保持不变。“配置任务”增加可选文字API区，配置保存到独立运行settings.json的text_provider，部分修改不会清空它，重启后仍读取；密钥通过本地持久环境变量或宿主安全凭据接入。“开始任务”每次展示当前Agent默认模型和第三方API两项，显示真实配置模型与可用性、缺项和发送上下文/调用费用说明。start及成品修订新任务均要求明确选择，原任务恢复保持原选择。

第三方路径真正执行HTTP调用，返回结果进入原结构/来源/规则/人审门；分析、策划、写作、文本审核、配图文字策划、复盘与零图终审分步骤执行。实际图片审核和带图最终联合审核仍使用已验证宿主视觉能力。图片生成仍使用独立图片API。

有请求账本、调用次数上限及跨进程锁，不自动切换模型或重发失败请求。收到响应后先保存，再原子提交状态；暂停前后内容、阶段、提示词和Schema指纹相同才复用，改过内容则阻断旧响应。请求期间暂停也保留已返回的有效响应，避免丢掉已取得的结果。

## 已知边界

仅支持同步OpenAI Chat Completions兼容协议、严格JSON对象响应；不支持任意原生厂商协议、流式输出、工具调用或第三方文字模型看图。请求次数不是实际金额预算，没有真实金额查询接口。确定性脱敏不是完整语义隐私审查。配置保存不代表密钥永不过期，也不保证删除数据或换设备后自动恢复。

使用说明、持久凭据设置、接口模板和收费恢复命令见[文字模型配置与选择](文字模型配置与选择.md)。历史版本和旧包留作可追溯记录，新安装请使用v1.3.0。
