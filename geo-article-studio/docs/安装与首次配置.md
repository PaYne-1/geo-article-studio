# 安装与首次配置

本包已支持不同Agent。请先按[多Agent安装与兼容性](多Agent安装与兼容性.md)选择目标目录和宿主配置。下列第1、2节是本机Hermes的具体安装示例；其他Agent不需要Hermes Python或目录。第3节的四库、产品、规则和图片配置适用于所有宿主。

Python 执行层要求 Python 3.11+；不要依赖 PATH 中恰好排在最前面的 Python。安装器自身只用标准库，生产依赖放在独立虚拟环境，不修改 Hermes 自身环境。下面的本机解释器路径来自 `Hermes环境核查.md` 的实测结果；在其他机器须重新探测。

## 1. 确认实际 Hermes 目录

```powershell
$basePython = 'C:\Users\Administrator\AppData\Local\hermes\hermes-agent\venv\Scripts\python.exe'
$source = 'D:\0-AI 项目\GEO\geo-article-studio'
& $basePython "$source\scripts\install.py" --host hermes --probe
```

本机 profile=`default`，技能父目录为 `C:\Users\Administrator\AppData\Local\hermes\skills`。其他 profile 以其会话实际探测结果为准。脚本不自动选择目标，不假定 WSL 路径映射，不修改 `config.yaml`。多 profile 或远程终端下，先在目标会话确认这些路径。

## 2. 安装完整技能及独立运行环境

```powershell
$skills = 'C:\Users\Administrator\AppData\Local\hermes\skills'
$data = 'D:\0-AI 项目\GEO\GEO图文运行数据'
& $basePython "$source\scripts\install.py" --host hermes --skills-dir $skills --data-dir $data
& $basePython -m venv "$data\venv"
$python = "$data\venv\Scripts\python.exe"
$skill = "$skills\geo-article-studio"
& $python -m pip install "$skill"
& $python "$skill\scripts\geo.py" --help
```

`$data` 是技能自动维护的内部工作区，无需作为第五个素材库日常维护。普通配置、索引、任务和学习规则放在其中；输出成品使用另一个配置路径；四个素材根目录只读。安装器将 data 路径记录在代码目录 `installation.json`，不会自动编造生产配置或图片参数。

也可从 ZIP 安装：在上述安装命令加 `--source '下载包完整路径.zip'`。目录源和 ZIP 都复制完整技能资源；排除 `.env`（保留 `.env.example`）、虚拟环境、缓存、日志、输出和运行数据等开发/运行内容。ZIP 会先检查目录穿越、绝对路径、符号链接、重复路径、Windows 保留名及解压容量，再解包。不要把真实资料存进技能源目录。

已有目标默认拒绝覆盖。备份升级用同一 data 路径：

```powershell
& $basePython "$source\scripts\install.py" --host hermes --skills-dir $skills --data-dir $data --upgrade
```

旧代码保存在技能父目录的同级 `geo-article-studio-backups` 下，命令输出准确备份路径。升级不删除外部数据，不改变已登记的数据路径；发现旧技能内部有 tasks/data 等运行目录时拒绝升级，先明确迁出并更新配置。卸载时仅移除明确的 `geo-article-studio` 代码目录；运行数据、四库、输出和备份需要单独保留，安装器不自动删除。

## 3. 首次配置

在实际 Hermes 会话中先确认使用 Qwen。本机默认当前为 DeepSeek，可用 `hermes chat --provider local-qwen -m qwen3.5:9b` 为本次会话明确选择已有本地 Qwen，不改全局配置。

输入 `/geo-article-studio 配置资料库`。宿主按 `references/forms.md` 收集四库、输出目录、真实禁限词清单位置和默认产品。已给信息直接预填；默认名称逐字为 `218切面侠`。用户维护的普通配置保存到独立 `$data` 中，执行命令始终显式带 `--config`，避免误读代码目录里的示例。

输入 `/geo-article-studio 配置API`，只填实际服务商、地址、接口文档、模型、环境变量名、参考图能力、尺寸/比例和请求或费用上限。技术细节按已核实协议推导；配置检查默认不发收费请求。不把密钥写入普通配置或粘贴到聊天。请在 Hermes 本地安全凭据设置或启动进程环境中提供所选密钥变量；常用名称 `GEO_IMAGE_API_KEY`。

若 terminal backend 是沙箱/远程，需要按实际 Hermes 支持的 `terminal.env_passthrough` 或技能所声明的环境变量机制传递该变量；只确认变量已接入，不打印值。禁止因为探测不到密钥就扩大读取 `.env` 或输出凭据。第三方服务未配置时仍可配置和分析，生成阶段保持阻断。

通过 `geo.py --config '实际配置完整路径' doctor` 检查路径、规则、解析器、图片接口和视觉声明。doctor 不调用收费生成；不因部分库尚未解析而声称全部读过。非结构化资料可先索引分析，批准产品事实后再用于正式稿。

## 4. 首次试跑与续跑

学习模式用 `/geo-article-studio 开始学习任务`，每阶段只批准明确 action 与 revision；`修改：……` 留在当前步骤并形成复盘，之后再次确认当前修订版。自动模式用 `/geo-article-studio 开始自动任务`，人工多选真实候选主题并明确每篇图片数量后，Hermes 在同一授权任务内循环处理动作直到完成或阻断。

暂停使用“暂停任务”；续跑使用“继续任务＋任务编号”。“查看规则”“更新规则”只作用于明确范围。没有活动任务或版本不明时，“确认”不能批准任意历史任务。详见 `references/hermes_bridge.md` 与 `docs/日常操作示例.md`。

## 5. 验证与限制

```powershell
& $python -m pip install "${skill}[test]"
& $python -m pytest "$skill\tests" -q
& $python "$skill\scripts\geo.py" demo --help
```

实际 Hermes 自然语言命中、Qwen 工具调用和图片视觉审核以 `docs/验收记录.md` 为准。示例配置中的 null、规则示例或模拟图片都不能作为生产通过证据。正常生产成功只返回实际成品目录路径；开发诊断、等待确认和失败阶段可提供必要说明。
