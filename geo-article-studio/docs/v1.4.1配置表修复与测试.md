# v1.4.1 配置表修复与测试

日期：2026-09-15。用户实际触发“配置任务”仍看到最少/最多字数和一长串协议技术参数。本次修复实际表单生成代码及宿主引导。

## 已修复

1. 从配置表values与sections移除article_length；开始任务仍选择short短篇600–800字或long普通长文至少1000字。旧settings字段仅供历史任务兼容，合并保存不擅自删除。
2. missing只列基础缺项；conditional_missing分别列有图任务及选择第三方文字API所需项。允许部分保存，默认宿主模型/零图不因不需要的API阻断。
3. 用户提供服务地址、模型、可选服务商及已有文档。适配器、接口路径、参考图能力/上限、支持格式移入agent_fields，Agent依据文档核对，不让用户猜。没有资料先保存并查找官方文档，不能臆测服务兼容性或付费探测。
4. 图片优先横版，实际尺寸由文档支持范围和用户确认确定，不再拿1024×1024作通用示例；已存比例与尺寸保持不变。
5. 区分已保存、默认、本次填写尚未保存、待补充；展示实际配置位置。configure合并保存后返回configuration，含本地检查、条件缺项及凭据是否接入当前进程。
6. form 配置任务 --format text或JSON.message直接提供中文表单，避免宿主照旧示例重建表格。只有这两个已有入口，没有新增触发词。

字段及保存映射见[表单](../references/forms.md)，中文安装升级及重新加载见[安装与首次配置](安装与首次配置.md)。不要把text_service写到text_provider，它只保存为service_labels.text。

全量源码实际结果见[原始测试输出](测试输出-v1.4.1.txt)。CLI中文输出、compileall、技能quick_validate亦实际执行。独立只读复核执行配置表和入口测试13项通过，未发现重要问题（计入全量结果，不重复相加）。

最终ZIP在隔离技能/数据目录安装后从安装副本运行全量测试；具体包哈希与结果在仓库dist/geo-article-studio-1.4.1.validation.md，报告位于包外，绑定最终包。

- 离线测试与CLI：本轮实际执行；完整回归仍包含本地HTTP模拟，模拟模型/视觉结果不代表真实模型质量。
- Hermes真实联调：本轮未执行；其他Agent真实生产会话也未重新验证。
- 真实文字API：未执行。
- 真实图片API：未执行。

本地check仅检查参数和环境变量，不请求供应商；保存成功不等于接口可用、文档已核实或视觉能力已验证。凭据仅报告布尔状态和变量名称，不在聊天收集或输出值。

没有实现通用网页协议自动解析器。协议识别由运行本技能的Agent阅读真实文档完成，未知协议仍需适配。未确认信息不会自动写成猜测参数。配置仍由现有configure按用户提供的补丁合并保存，不能将整份表单的空字段覆盖已存值。

代码与ZIP已更新不代表用户所有安装位置已更新。本轮仅测试隔离安装，未找到默认用户技能目录中的现有geo-article-studio安装；未知位置的副本需要用新包升级并重新加载。长期数据目录继续复用。
