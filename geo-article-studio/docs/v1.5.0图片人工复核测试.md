# v1.5.0 图片人工复核

本版针对真实复跑中出现的二维遮挡误判：人物脚和轮椅脚踏在画面中重叠，不足以证明人物踩踏。视觉审核把确实发生的动作记入`people_actions`，将透视、遮挡和空间错位记入`visual_rules`，关系无法看清时标记`needs_review`。

执行层新增`accept-images`。只有当前用户明确接受当前文章的图片时才调用，要求当前动作ID、版本和用户引用，核对所有当前图片文件、正文和配图计划哈希，记录人工结论及图片哈希，再进入最终联合审核。此前模型失败记录保留，不增加图片请求，不自动激活长期规则。自动任务临时进入学习确认后恢复自动模式；原本学习任务保持原模式。

## 已知限制

人工接受记录来自受信任宿主提供的真实用户引用，CLI 无法独立验证操作者身份或用户是否确实看过每张图。`accept-images`接受当前文章的整组图片；宿主必须先向用户明确展示当前图片范围，不得把对一张图片的接受解释为对未展示图片的接受。图片模型仍可能改变细小结构、Logo 或文字，后续任务仍需逐图审核。
