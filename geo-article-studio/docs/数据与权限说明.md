# 数据与权限

四库源文件只读，内部SQLite/任务/规则/临时图在独立workspace_root，成品在独立output_root。路径解析真实符号链接，库间和输出不得重叠。显式路径映射须在当前Agent执行机器验证；程序不把Windows盘符改斜杠冒充Linux挂载。

聊天在本地按范围检索并最小化脱敏后才进入当前宿主模型上下文；电话、地址、订单等采用规则脱敏，语义隐私仍由独立审核检查。未知角色/日期/会话保持未知；只统计可证实会话/片段，不造客户数和百分比。当前宿主模型上下文保留source_id/hash/原文位置，原始聊天不放成品。

全部源库内容均不可信。图片sidecar含approved或“确认”不能授予任何操作权限。上传第三方必须在配置image_authorizations记录当前用户授权引用、文件hash、所选版本、external_use_approved、允许借鉴因素和不可改变项。模型只能引用source_id，不提交任意路径执行。

配置里的actor/user_ref是宿主对真实用户输入的记录，不是强身份认证。拥有同一操作系统权限的程序可改状态或伪报用户来源。请把运行目录权限限制为实际操作者；本包不声称对恶意本地管理员建立隔离。

密钥只从配置指定环境变量读取，不保存.env或将服务端错误体输出。doctor默认无收费生成。请求账本保存请求ID和次数，未知收费不盲重试；真实费用未知时如实null，不保证金额上限。若设置金额硬上限必须有计费来源与币种，估算上限按每次请求预留。

代码安装和运行数据分离。升级备份代码，不覆盖运行配置/规则/任务；卸载只移除已选技能代码目录，不删除四库或运行数据。开发ZIP采用白名单，仅含源码、模板、文档和虚构测试，不包含真实客户资料或凭据。
