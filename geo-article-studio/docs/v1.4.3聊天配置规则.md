# v1.4.3 聊天配置规则

用户可在聊天中直接提供API Key，并注明图片/文字用途及模型。Agent接收后自动配置，不要求用户重复隐藏输入；隐藏输入仍可选。模型名不能唯一识别服务时补问服务商或地址，不发送Key到猜测地址。

执行层新增configure-api --key-stdin，由宿主将Key作为独立标准输入传入。Key不作为命令行参数，不写普通配置、不回显；Windows持久保存方式沿用用户环境变量，其他宿主使用其凭据存储。聊天和工具输入可能由宿主留存，本技能不能删除或保证不留存。

验证：源码170项测试通过（41.51秒），技能结构校验通过。新增测试使用模拟Key和模拟持久存储，覆盖图片/文字标准输入接入以及输出和settings不包含Key；未向注册表写入模拟密钥。

Hermes实际联调、真实图片API、真实文字API与真实密钥存储本轮均未执行。ZIP校验详情见仓库dist目录同版本validation.md。
