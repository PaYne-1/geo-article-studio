1. 安装与升级

下载完整 ZIP 后，在 Hermes 所在电脑安装。不要只复制 SKILL.md；ZIP 内的脚本、规则和参考文件都需要保留。

  1. 确认 Hermes 当前 profile 的 skills 父目录，以及一个单独的运行数据目录 data。
  2. 用技能包中的 scripts/install.py 安装 ZIP。首次安装不加 --upgrade。
  3. 创建运行数据目录的虚拟环境并安装依赖。重启或新开 Hermes 会话，使它重新读取新版技能。
$basePython = '实际的Python 3.11以上解释器路径'
$zip = '下载的geo-article-studio-v1.6.5.zip'
$skills = 'Hermes当前profile的skills目录'
$data = '独立运行数据目录'

& $basePython '解压后的geo-article-studio\scripts\install.py' --host hermes --source $zip --skills-dir $skills --data-dir $data
& $basePython -m venv "$data\venv"
$python = "$data\venv\Scripts\python.exe"
& $python -m pip install "$skills\geo-article-studio"
& $python "$skills\geo-article-studio\scripts\geo.py" --help
升级时必须继续使用原来的 $data，这样已保存的路径、配置、任务、学习规则和选题分析缓存才会保留。
& $basePython '解压后的geo-article-studio\scripts\install.py' --host hermes --source $zip --skills-dir $skills --data-dir $data --upgrade

2. 首次配置

在 Hermes 对话中发送：配置任务。可以分次填，保存配置时不会自动发起图片或文字 API 请求。

项目需要提供的内容
基础配置产品名称、聊天库路径、产品信息库路径、参考图库路径、产品图库路径、成品保存目录。
图片 API图片模型名称与 API Key；可选填写每任务图片调用上限。图片必须固定 3:4，且每张都展示当前产品。
第三方文字 API可选。文字模型名称与 API Key。若不配置，开始任务时可选择当前 Agent 默认模型。

API Key 可以由你在当前对话中主动提供，并注明“图片”或“文字”及模型名称；技能只保存安全凭据或环境变量引用，不能把密钥写入普通配置、成品或 Git。

3. 开始一个自动任务

发送：开始任务。然后填本次模式、文字来源、目标、发布平台、目标 AI、篇幅和可选的图片审核策略。

自动模式
当前 Agent 默认模型
图片审核策略：不审核 直接用
目标：品牌曝光 / 型号种草 / 用户转化 / AI引用
发布平台：知乎 / 头条 / 搜狐 / 百家号 / 企鹅号 / 网易
目标AI：DeepSeek / 豆包 / 文心一言 / 元宝
短篇 600–800字
图片调用上限：5
完整列出一个字段的所有候选项，或直接写“全选”，技能会按全选继续，不再额外弹出确认框。只填写部分候选时，技能会按你的实际选择处理。

文字来源：“当前 Agent 默认模型”不需要文字 API；“第三方文字 API”会使用已配置的文字模型。每个新任务都要明确选择一次。

4. 选题生成后怎么继续

聊天库分析完成后，助手会返回类似 T01、T02 的问题型标题候选。此时不要再次发送“开始任务”，直接选主题并给出篇数、每篇图片数：

选择 T01，写1篇，每篇2张

多个主题可一次说明：

选择 T01、T03；T01写1篇，每篇2张，T03写2篇，每篇1张

这一步既是标题确认，也是当前任务的生产授权。系统会使用已经完成的聊天分析，不会重新分析聊天记录。

5. 暂停、换会话和续跑

情况怎么说结果
暂时停止暂停任务保存当前状态，不发起新的请求。
原会话继续直接发送选题/确认/修改内容沿用当前任务，不重新分析。
断开后恢复继续任务＋任务编号校验已完成文件，不重复生成已合格内容。
修改当前结果修改：具体要求保留旧记录，修改当前阶段并复审。
不要用“开始任务”恢复旧任务。它会创建新任务；只有配置、资料、规则和任务需求完全一致时，新任务才可能复用选题分析缓存。

6. 配图与审核

  • 所有图片固定 3:4 竖版，必须出现已批准的当前产品图。
  • 图片提示词从正文段落生成，并绑定正文信息、产品图、参考图库风格、场景透视和光影融合要求。
  • 默认逐图审核。自动模式下明确选择“不审核 直接用”时，图片经技术校验后直接采用；成品会写入 图片审核状态.txt，标明未做视觉审核。
  • 无论是否视觉审核，图片外传授权、参考图借鉴范围、请求上限和文件校验都仍然生效。

7. 成品保存在哪里

成功后，助手只返回真实成品根目录的绝对路径。目录名采用：时间_产品名_三位序号。每篇文章有独立子目录：

成品保存目录

8. 常见问题

我只想让它复用选题，不重复分析聊天库。

在同一个任务里，选题出来后直接发送“选择 T01，写1篇，每篇2张”。断开后使用“继续任务＋任务编号”。不要重新发送“开始任务”。

为什么任务停住？

通常是等待你选择主题、填写篇数/图片数，或缺少产品事实、产品图授权、参考图授权、图片 API 配置、图片额度或视觉能力。查看当前助手消息中的缺项或阻断原因即可。

能否不生成图片？

可以。选题时明确每篇为 0 张图。零图文章不要求图片 API 完整配置。

能否修改已生成文章？

可以发送“修改：……”；系统会保留历史版本。实质改正文后，关联配图会失效，需要按当前任务规则重新处理。

为什么没有立即给出成品路径？

只有标题、正文、实际图片和必要审核/技术校验达到当前任务要求后，技能才返回真实成品目录。等待确认或失败阶段不会伪造成功路径。
