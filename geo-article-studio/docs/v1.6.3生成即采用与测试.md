# v1.6.3 生成即采用与测试

用户要求自动带图任务生成图片后直接使用，不执行视觉审核。新任务显式选择`image_review_policy=direct_use`，默认及旧任务维持`reviewed`。执行层记录用户引用和最终图片哈希，跳过IMAGE_REVIEW；FINAL_REVIEW仅查文章与真实文件，不允许提交image_alignment或假称已看图。成品独立保存`图片审核状态.txt`，注明“未做视觉审核”。

产品图与参考图的逐源外传授权、接口协议、请求次数上限、图片解码/尺寸/格式/哈希及文章事实、GEO、内容审核不因direct_use豁免。Hermes报告的20 MB输入限制仍需单独处理；改变图片内容后须按新哈希重新授权。

离线模拟测试：2026-09-17执行`.venv\Scripts\python.exe -m pytest -q`，结果**221 passed、2 skipped**，退出码0；使用虚构资料、临时文件及模拟图片服务。新增测试覆盖显式策略、默认保留审核、学习模式拒绝、外传授权不豁免、当前编辑标准下无视觉能力选题、生成后跳过记录、未审核成品说明、伪造视觉检查拒绝和图片哈希篡改拒绝。

安装烟测：完整ZIP经`install.py`安装到隔离通用宿主目录，已安装脚本`--help`可运行；ZIP完整性检查无损坏。已用`--upgrade`将本机Hermes `bot-profile` 的旧v1.6.2技能备份后升级到v1.6.3，沿用既有NAS data_dir；使用其已有独立Python运行已安装技能的`form 开始任务`及`start --help`通过。表单读取到固定目标4项、平台6项、目标AI4项和两种图片审核策略。升级未运行收费图片API。
