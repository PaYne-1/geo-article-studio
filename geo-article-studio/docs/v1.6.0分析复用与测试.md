# v1.6.0 跨任务分析复用与测试

本版增加运行工作区中的版本化主题分析缓存。只有产品及版本、检索来源及哈希、已批准事实、正式规则、运行配置、聊天检索范围、额外需求、GEO简报、文字来源和编辑标准均一致时，`ANALYZING`才返回`NEEDS_TOOL/reuse-analysis`。执行工具再次核验来源文件、事实、规则、缓存结果和动作版本，记录来源任务及结果哈希，然后停在人工选题。文章策划、写作、图片生成与各轮审核均不复用。显式`refresh`和`start --fresh-analysis`强制重新分析。这是本地持久化缓存，不依赖OpenViking，也不提供跨产品的语义记忆。

## 限制

缓存按完整输入严格匹配，因此资料索引结果或配置发生细小变化也可能重新分析。缓存只复用已完成的主题分析，不从旧文章提炼新事实，不跨产品共享选题，也不替代人工选题或审核。具有本地运行工作区写权限的操作者仍可改写任务与缓存文件；本地文件哈希校验不构成外部身份认证。
